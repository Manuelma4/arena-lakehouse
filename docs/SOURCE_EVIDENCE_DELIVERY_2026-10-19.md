## Included behavior

Current's **Source evidence** disclosure shows the catalogue, metric definitions,
declared lineage, cumulative quality counters, quarantine groups and checksum
references for the selected capture. The companion is optional and bound to the
provider, snapshot, publication and original manifest. Missing or mismatched
evidence produces an explicit unavailable/conflict response.

The producer exports seven checked metadata files. The consumer reads those
files independently. The GET inspector and fixed stateless POST summary preserve
the distinction between retained facts, declared metadata, source-check freshness
and reviewable recommendations. The POST does not provide arbitrary model answers
or a saved investigation. Existing team research, regulation statistics, chat and
saved replay remain separate paths.

## Continuing on another computer

Pull the same checkpoint branch in both repositories. Private source captures,
metadata companions, media registries, SQLite state and `.env` remain outside Git.
A code pull does not restore those files or make old captures current.

Given an already retained, validated canonical snapshot, the producer's explicit
`python -m arena_lakehouse.source_evidence --snapshot <snapshot> --output <packet>`
command creates a companion without collecting data. The consumer expects packets
under `<evidence-root>/<provider>/<snapshot-fingerprint>/`; configure the local
root with `ARENA_SOURCE_EVIDENCE_WORKSPACE`. Use the exact selected publication,
rather than attaching an arbitrary directory with a matching team name.

Durable source-evidence investigations, real-model evaluation, actual Linux atomic
publication, broader source coverage, native Spark scale and managed Databricks
execution remain acceptance work. This approval does not authorize fresh provider
collection, national Current activation or model operation. The portfolio goal is
still incomplete.
